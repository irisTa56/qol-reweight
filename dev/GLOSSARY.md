# Glossary

The code and its comments are written without Japanese text, which keeps columns aligned in an editor.
This file pairs each English name used there with the Japanese term it stands for.

## Grid squares

The terms are the Statistics Bureau of Japan's, from [`地域メッシュ統計の特質・沿革`](https://www.stat.go.jp/data/mesh/pdf/gaiyo1.pdf), which the code calls its outline of grid square statistics.

| In the code | Japanese term |
| --- | --- |
| grid square, mesh | `地域メッシュ` |
| grid square code, mesh code | `地域メッシュ・コード` |
| first-level square | `第1次地域区画` |
| second-level square | `第2次地域区画` |
| third-level square | `基準地域メッシュ(第3次地域区画)` |
| half grid square | `2分の1地域メッシュ` |
| 2 km square | `2倍地域メッシュ` |
